# VOLTA-ZK — Claude entry point

`AGENTS.md` is the authoritative durable instruction set.  This file is only
an entry point and deliberately does not duplicate milestone history, gates or
measurements.

Before any task:

1. read `AGENTS.md`;
2. read `docs/c7.1/design.md`;
3. read the relevant specifications, security and test instructions linked there.

Treat a hard stop in the ledger or active design as binding.  Do not replace it
with an assumption, treat a component test or analytic screen as a full-chain
result, or contact a provider/pod without the recorded owner authorization.

Update the affected active document and preserve dated decisions/evidence in
`docs/c7.1-history/`. Keep raw benchmark records append-only under
`benchmarks/results/`.
